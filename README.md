# 高校数学 毎日4択クイズ → Teams配信

数学I・A・II・B・Cの4択問題を、毎朝5問（易しい順）Teamsのチャネルに自動投稿します。
カードの①〜④のボタンを押すと、その場で正解・不正解と解説が表示されます（サーバー処理は不要）。
一度出題した問題は、二度と出題されません。

## 全体の仕組み

```
GitHub Actions（毎朝7:00 JSTに自動実行）
   └─ scripts/send_question.py が questions/*.json から今日の5問を選ぶ
        └─ Teams「ワークフロー」の Webhook URL に、5問を順に POST
             └─ Teamsのチャネルに Q1〜Q5 のカードが投稿される
```

## 1日の出題ルール

- 毎日5問。難易度1（基礎）→ 難易度5（標準）の順に、Q1〜Q5として投稿します。
- 難易度ごとに1問ずつ。科目（I・A・II・B・C）は毎日ずらして割り当て、偏らないようにしています。
- 出題済みの問題は `questions/history.json` に記録され、二度と出題されません。
- 難易度の問題がなくなると、その日の配信は**失敗**して止まります（同じ問題を繰り返さないため）。
  残りが約7日分になると、GitHubのActionsの実行結果に警告が出ます。問題を追加してください。

| 難易度 | 目安 |
|---|---|
| ★☆☆☆☆ (1) | 用語・公式の確認 |
| ★★☆☆☆ (2) | 基本の計算（1ステップ） |
| ★★★☆☆ (3) | 基本の計算（2ステップ以上） |
| ★★★★☆ (4) | 教科書の例題〜章末レベル |
| ★★★★★ (5) | 標準レベル（共通テスト・入試基礎） |

## セットアップ

### 1. GitHubにアップロード済みであること

このリポジトリ（コード一式）がGitHubにあり、Actionsが有効になっている状態にします。

### 2. Teamsのワークフローで Webhook URL を作る

1. Teamsの左端アプリ一覧から **「ワークフロー」** を開く
2. 検索欄に `Webhook` と入力し、**「Webhook アラートをチャネルに送信する」** を選ぶ
   （「特定のユーザーから」「組織内のユーザーから」と付くものは、GitHubから送れないので選ばない）
3. 投稿先の **チーム** と **チャネル** を選んで作成する
4. 完了画面の **「Webhook リンクをコピー」** でURLをコピーする

このURLを知っていれば誰でもそのチャネルに投稿できます。GitHubのSecret以外には保存・共有しないでください。

### 3. GitHubにURLを登録

1. リポジトリの「Settings」→「Secrets and variables」→「Actions」
2. `POWER_AUTOMATE_URL` という名前のシークレットに、手順2でコピーしたURLを登録（既にあれば更新）

### 4. 動作確認

1. リポジトリの「Actions」タブ →「Daily Math Quiz」→「Run workflow」で手動実行
2. Teamsのチャネルに Q1〜Q5 のカードが届き、①〜④を押すと正誤と解説が出れば成功です

手動実行も本番と同じく5問を投稿し、出題済みとして記録されます。テストしたいときは、投稿先を
テスト用のチャネルにしてから行ってください。

エラーの場合は「Actions」タブの実行ログに原因が表示されます。

## 問題の追加方法

`questions/` フォルダの中に科目ごとのJSONファイルがあります。

| ファイル | 科目 |
|---|---|
| `math1.json` | 数学I |
| `mathA.json` | 数学A |
| `math2.json` | 数学II |
| `mathB.json` | 数学B |
| `mathC.json` | 数学C |

以下の形式のオブジェクトを、配列の最後に（カンマで区切って）追加します。

```json
{
  "id": "math1-L3-07",
  "subject": "数学I",
  "unit": "二次関数",
  "level": 3,
  "question": "問題文をここに書く",
  "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4"],
  "answer": 0,
  "explanation": "解説文をここに書く"
}
```

- `id`: 全ファイルを通して重複しない文字列（例: `math1-L3-07`）
- `level`: 難易度 1〜5（上の表を参照）
- `answer`: 正解の選択肢の**番号（0始まり）**（0=①、1=②、2=③、3=④）
- 選択肢は**4つ**にしてください（同じ内容の選択肢は不可）
- 指数は `x²` `x³` のように直接書けます。`x^2` `x^3` と書いても、投稿時に `x²` `x³` に自動変換されます
- 1日5問なので、難易度ごとに5日で各科目1問ずつ消費します。全体の目安は「難易度ごとの問題数 ÷ 1日1問」日分です

問題を追加・変更してGitHubにアップロードすると、「Check Questions」が自動で書式を検査します
（緑のチェックなら問題なし、赤い×なら実行ログにエラー内容が出ます）。

## 配信時刻・科目の順番を変える

- 配信時刻: `.github/workflows/daily-quiz.yml` の `cron: "0 22 * * *"` を編集
  （UTC基準です。JSTにするには「JSTの時刻-9時間」を指定）
- 平日のみにする場合は `cron: "0 22 * * 0-4"`（日〜木のUTC22時 = 月〜金のJST朝7時）
- 科目の順番: `scripts/send_question.py` の `SUBJECT_ORDER` を編集
